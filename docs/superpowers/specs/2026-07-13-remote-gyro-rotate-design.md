# 远程陀螺仪闭环原地转向设计

## 目标

在现有 ESP-01S 调参网页中提供左转 90 度、右转 90 度和指定角度转向。正角度为左转（逆时针），负角度为右转（顺时针），允许范围为 -180 到 +180 度。

转向是相对角度闭环：以静止零偏校准后的 MPU6050 Z 轴角速度积分为主反馈。MPU6050 没有磁力计或外部视觉基准，因此本功能不宣称绝对世界航向；实机验收以重复转向的相对角度误差为准。

## 架构与数据流

浏览器的转向控件经 Flask-SocketIO 调用主机请求管理器，发送带单调请求 ID 的 TC1 `cmd` 帧：`{"cmd":"rotate","deg":<signed-degree>}`。固件验证命令、启动独立的原地转向状态机，并以 ACK 确认接受或拒绝。遥测扩展转向阶段、目标角、实测相对角、误差和失败原因；主机将其推送到界面。

固件状态机不复用循迹的直角弯逻辑。它在开始时保存航向积分基线并命令双轮反向运动，控制周期中按相对航向误差调节转向输出，接近目标时降速，满足误差和低角速度条件后停车并报告完成。

## 安全门与故障处理

仅当安全状态为 READY、循迹未运行、MPU6050 通信正常且已静止校准、目标角度在范围内时接受命令。执行期间任何停止命令、通信看门狗、安全状态撤销、IMU 读取异常、编码器无响应、方向不符或动作超时都必须在同一控制周期停止两电机，并通过 ACK/遥测给出原因。

网页在请求发出至收到终态期间禁用所有转向控件；保留停止按钮。重复点击、超范围值、离线和非 READY 状态应在主机侧预检并在固件侧再次验证。每个会改变电机运动的命令均具有可观察 ACK。

## 校准与控制

静止校准继续使用现有均值和标准差检查，且只接受校准成功后的 IMU 数据。转向使用陀螺仪角度反馈，编码器不参与角度估计，只作为反向轮速、堵转和方向异常的安全检查。控制器包含最小起转输出、接近目标的减速区、输出限幅、完成角度容差、低角速度保持时间和与角度相关的超时上限；全部参数集中于固件/主机共享的调参定义，范围一致。

## 测试与验收

先添加主机协议测试（请求格式、ACK/拒绝、UI 状态）和可在主机编译的纯 C 状态逻辑测试（方向、范围、完成判定、超时和故障停止）。构建通过后再烧录。

实机测试前，小车应架空或留有安全空间。通过 J-Link/RTT 记录 IMU 零偏、校准标准差、角度积分、目标/误差、两侧编码器和终态。验收顺序是：静止漂移观测、低速 ±90 度、连续重复 ±90 度、再扩展至指定角度。不能以单次目测替代测量；最终容差以实测日志和用户选择的赛道要求为准。
