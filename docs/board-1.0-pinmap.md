# 板子 1.0 固件引脚映射

本页依据 `Netlist_板子1.0_2026-07-18.tel` 与当前 MSPM0G3507 SysConfig 交叉核对。网表中的 `MSPM0G3507.1~80` 是核心板模块焊盘号，不是 LQFP-64 裸芯片管脚号；固件统一使用 `PAx/PBx` 名称。

## 保留外设

| 功能 | 引脚 / 外设 | 固件约束 |
|---|---|---|
| 左电机双 PWM | PA22 / PA15，TIMA0_CCP1/2 | AT8236 两输入 PWM |
| 右电机双 PWM | PB0 / PB11，TIMA1_CCP0/TIMG6_CCP1 | AT8236 两输入 PWM |
| 左编码器 | PB21 / PB22 | 上拉输入，GPIOB 双边沿中断 |
| 右编码器 | PB12 / PB13 | 上拉输入，GPIOB 双边沿中断 |
| 鱼眼循迹 SDA/SCL | PA0 / PA1，I²C0 | 地址 `0x48`，400 kHz，模块侧 5 V 上拉 |
| OLED SDA/SCL | PA18 / PA17，I²C1 | 地址 `0x3C`，400 kHz，3.3 V 上拉 |
| IMU660RB CS/MISO/MOSI/SCLK | PB6 / PB7 / PB8 / PB9 | SPI1 Mode 0，禁止被软件 I²C 改写 |
| ESP-01S TX/RX | PA8 / PA9 | UART1 + DMA |
| 调试串口 TX/RX | PA10 / PA11 | UART0 + DMA，SysConfig 已锁定 |
| SWDIO / SWCLK | 专用 DIO / CLK | J-Link 接口未接 RESET |

PA17 与 PA18 在 MCU 端分别是连续的 `PINCM39/PINCM40`，可组成 I²C1 的 SCL/SDA；这里没有使用 PB18。两套 I²C 必须各自上拉、禁止交叉连接，但鱼眼、OLED 和主控必须共地。旧灰度 PA26、PA24、PB24、PA27 与 ADC 外设已从当前 SysConfig 和 Keil 工程释放。

## 板载交互器件

| 器件 | GPIO | 电气关系 | 固件行为 |
|---|---:|---|---|
| 状态 LED `LED3` | PB4 | LED 经 4.7 kΩ 到 GND，预期高有效 | 唯一受控 LED；任一已消抖按键事件切换状态 |
| 蜂鸣器 | PB5 | 按实物接线配置为低有效，上电默认输出高电平 | 普通按键事件 1 声；实际校准动作 2 声 |
| K1 / SW1 | PB15 | 内部上拉，按下接 GND | 启动 |
| K2 / SW2 | PB16 | 内部上拉，按下接 GND | 停止 |
| K3 / SW3 | PB2 | 内部上拉，按下接 GND | 短按切换 OLED 页面；长按电机比例标定 |
| K4 / SW4 | PA30 | 内部上拉，按下接 GND | 静止时切换鱼眼黑线 `0/1` 极性 |

蜂鸣节奏由非阻塞状态机推进：单声为 60 ms 开；双声为 60 ms 开、60 ms 间隔、60 ms 开。状态机在主循环中推进，不使用 `Bsp_Delay_ms()`，不会阻塞 5 ms 循迹控制。

K3 长按的旧电机比例标定本身仍是约 1.3 s 的维护模式阻塞流程。本版只允许在 `Safety READY` 且 `Track IDLE` 时进入，并在标定函数返回后再发两声提示，防止行驶中误触或把短音拖成长鸣；执行前仍必须架空车轮。

网表只标注蜂鸣器为 `2.4kHz`，未给出确切料号，无法仅凭网表确定有源或无源。本版根据实物反馈按低电平直流使能实现，适用于有源蜂鸣器；若实物是无源蜂鸣器，应把 PB5 切换到 TIMA1_CCP1 的约 2.4 kHz 硬件 PWM，不能在主循环里软件翻转引脚。

## OLED 与鱼眼状态

- OLED 已正式绑定 I²C1：PA18=SDA、PA17=SCL、`0x3C`、3.3 V；上电稳定 100 ms 后初始化。
- 显示内容每 100 ms 生成一次，主循环每 5 ms 最多刷新一个脏字符（最多 28 个 I²C 字节），不会在 ISR 或控制路径整屏刷新。
- OLED 缺失、NACK 或 I²C1 故障只会禁用显示并记日志，不参与运动安全判定。
- 鱼眼使用独立 I²C0：PA0=SDA、PA1=SCL、`0x48`；每 5 ms 非阻塞读取一个 7 字节半帧，约每 10 ms发布一次完整 12 路快照。
- 鱼眼板载标定：长按板载 K1 进入采集，短按板载 K1 采白底，短按板载 K2 采黑线。
- 禁止把 OLED 绑定到 PB8/PB9：这两脚属于 IMU660RB SPI1。

## 网表待复核项

- `5V`、`12V` 同时被当作网络名和多个器件位号，导出的 `.tel` 出现同一端点跨网络重复，不能据此可靠验证部分电源排针与电源指示灯。建议在原理图中把这些器件重命名为唯一 `Jx/Dx` 位号后重新 ERC/导出网表。
- OLED 与鱼眼不在当前板 1.0 网表中，焊接前仍需用万用表核对实际扩展排针上的 PA0/PA1/PA17/PA18、3.3 V、5 V 与 GND。
